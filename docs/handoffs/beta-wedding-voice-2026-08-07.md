# Бета — «Свадьба в Минске»: передача состояния

Дата фиксации: 7 августа 2026, 18:32 МСК  
Продукт: Gate / Бета, групповое пространство «Свадьба в Минске»  
Владелец: Марк

## Цель MVP

Для каждого голосового сообщения в группе Бета должна:

1. Сразу отправить видимое сообщение о приёме: голосовое принято и расшифровывается.
2. Скачать и расшифровать голосовое.
3. Сохранить результат в текущей базе Gate.
4. Отправить в группу структуру с разделами «Факты», «Решения», «Задачи», «Вопросы».

Для обычного текстового сообщения Бета отвечает той же структурой.

В MVP нет recovery-ключей, Git-выгрузок, hourly-checkpoint или отдельного backup-контура. Данные остаются в рабочей базе Gate.

## Незакрытый критерий приёмки

Нельзя считать пользовательский сценарий принятым только по счётчикам Gate или пустой очереди Telegram.

Нужно фактически увидеть в группе после **нового** короткого голосового два сообщения Беты:

1. немедленное подтверждение приёма и расшифровки;
2. затем расшифровку/структуру с фактами, решениями, задачами и вопросами.

Если любого из двух сообщений нет, следующий Work должен:
- зафиксировать время нового сообщения и приложить скриншот;
- сопоставить Telegram webhook, логи Gate и записи `beta_wedding_voice_jobs` / `beta_wedding_voice_deliveries`;
- исправлять только подтверждённую причину;
- выпускать правку через PR, CI и Railway deploy.
